# SPI wiring to Arduino Pro Mini

The Pro Mini SPI pins are fixed:

| Pro Mini Pin | Function |
| ------------ | -------- |
| D13          | SCK      |
| D11          | MOSI     |
| D12          | MISO     |

## nRF24L01 → Pro Mini connections

    nRF24L01 VCC  ---> LiPo / Pro Mini VCC (3.3V)
    nRF24L01 GND  ---> GND

    nRF24L01 SCK  ---> Pro Mini D13
    nRF24L01 MOSI ---> Pro Mini D11
    nRF24L01 MISO ---> Pro Mini D12

    nRF24L01 CE   ---> Pro Mini D9
    nRF24L01 CSN  ---> Pro Mini D8
    nRF24L01 IRQ  ---> (optional) Pro Mini D2

✅ CE and CSN can be **any GPIO**  
✅ IRQ is optional (polled operation works fine) [\[projecthub...arduino.cc\]](https://projecthub.arduino.cc/tmekinyan/how-to-use-the-nrf24l01-module-with-arduino-813957), [\[howtomecha...ronics.com\]](https://howtomechatronics.com/tutorials/arduino/arduino-wireless-communication-nrf24l01-tutorial/)

# ⚠️ CRITICAL: decoupling capacitor (do not skip)

This is **mandatory**, not optional.

    nRF24L01 VCC ----||---- GND
                   10µF to 47µF

Place it **as physically close to the module as possible**.

Without this capacitor:

*   Random packet loss
*   Lockups
*   “Works on breadboard, fails in enclosure”

This is documented in essentially every reliable nRF24L01 reference design. [\[alw1746.github.io\]](https://alw1746.github.io/projects/NRF24L01/index.htm)

# Two common mistakes (avoid these)

❌ Power nRF24L01 from RAW pin  
❌ Skip the decoupling capacitor

Both will cause **intermittent failures that look like software bugs**.
